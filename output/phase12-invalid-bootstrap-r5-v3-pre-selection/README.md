# Superseded held-out bootstrap artifact

The preserved bootstrap artifact was produced before the post-hoc Reflection
test supplement was completed. It compares only Prompt and Skill against the
baseline, so it cannot support the approved effective test matrix. It is
retained unchanged for audit history and is not the current Phase 12 report
input.

The canonical artifact is regenerated from the complete active live-test
records after the Reflection supplement and uses candidate-minus-baseline
labels and values.
