# Superseded Skill test batch

The original `r5-test-skill` batch stopped after 49 provider calls when
transport failures blocked the remaining 23 trials. The raw 72-row file,
blocked-case list, 23 recovery batches, and recovery map remain here for
audit. Active scoring uses the 49 recorded rows plus the 23 separately
reserved recovery results in `output/phase12/`; this archive is never counted
as another set of calls.
