## 需求与补货
- 业务用户把交付目标写进 Agent Run 目标 (goal), 由系统按授权范围读取库存、未结需求与在途采购
- 时间窗口缺省 90 天: 当前库存 + 在途采购 + 未来 90 天需求

## 采购计划
- 系统确定性计算每个物料的风险: 缺货 / 重复采购 / 供应充足 / 输入不足
- 缺货 (净位置 < 0): 建议补货, 缺口数量由公式计算
- 重复采购风险 (净位置 >= 0 但已有未结 MR/PO): 不建议重复采购
- 输入不足: 缺少必需数据时不估算, 明确列出缺失项

## 审批与执行
- MR Draft / PO Draft: 发起人显式确认
- PO Submit / 收货 / 开票 / 付款: 由不同于发起人的有权审批人授权
- 所有写操作先重新校验身份、权限、当前状态与过期条件
