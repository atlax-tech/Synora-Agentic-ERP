### 10. 面试官可能追问的技术细节以及如何回答

1. 为什么不让 ERP controller 在 `set_missing_values()` 时顺便产生 Item Price？——那可能把未经批准的请求体 rate 写成新价格，不能作为提议阶段的事实源；策略必须先用只读 resolver 证明已有价格。
2. 为什么要求 Price List 币种与 proposal 一致？——当前 Draft writer 固定 conversion rate=1，跨币种不做隐式换算，避免把未审核的汇率差异写入金额。
3. 为什么比较 Decimal 而不是 float？——金额和单价必须避免二进制浮点误差，源值和提议值先转 Decimal 再比较。
4. 首次 app-test 为什么失败仍要保留？——它证明新增门禁确实拦住了无源价格，随后只修测试夹具/context 根因，不把失败改写成“未发生”。
5. 这是否已经证明生产价格治理？——不是；当前只在固定上游和隔离开发站点验证，企业站点的价目表、权限和 Workflow 仍需运行时取证；`待练习`
