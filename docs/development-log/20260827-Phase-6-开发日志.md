1. 为什么数据库里的 JSON 字段还要再做 parser？——数据库只保证能存文本，不保证字段、枚举、重复 key、数字精度和 digest 正确；parser 是信任边界，DocType controller 是第二道防线。`待阶段答疑`
2. 为什么 state_version 不能只靠 Python 先读再写？——两个请求可能同时读到同一版本；行锁和 CAS 把“我基于哪个版本推进”变成数据库可验证事实，失败者返回冲突。
3. 为什么失败 Receipt 可以没有 ERP target，而 success 不行？——失败可能发生在 insert 前；success 必须证明 ERP 已有目标且关键字段 read-back 成功，传输层 200 不能替代这个证据。
