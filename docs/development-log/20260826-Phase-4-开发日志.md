- 为什么要同时做 preflight 和 post-response budget check？preflight 防止在无法证明预算时发起付费调用，post-response 用服务商实际 usage 检查其是否超出 per-call、累计 token、成本和 wall-clock 限制。
- 为什么重复调用和 no-progress 不是同一个 guard？重复调用比较完整的工具名加 canonical 参数；no-progress 比较 Observation digest，因此参数不同但返回相同事实时也能停止。
- 为什么 P4.4 的并发 registry 不能替代数据库锁？它只在单进程内提供原子 claim；跨进程、重启恢复和持久任务需要 Phase 5 的 durable checkpoint/锁语义。

### 10. 面试官可能追问的技术细节以及如何回答

- 为什么 `Action.call_key()` 要排序 JSON 键？因为对象键顺序不是业务语义，排序后同一组参数才能稳定识别重复。
- 为什么 Observation 需要 digest？Trace 只保存有界摘要，digest 用来判断是否有新事实且不必重复保存敏感原文。
- 为什么 P4 loader 不直接复用 P3 `EvaluationCase`？P3 验证业务风险结果，P4 验证轨迹和停止语义，分开 schema 可避免字段悄悄互相污染。
