- 为什么 Trace 不直接保存 Runtime 原文？答：网络响应不可信且可能含敏感信息，只允许固定字段、digest 和 bounded safe summary。

### 9. 本轮任务大白话讲解

- 为什么 `STARTED` 不重放？答：跨进程调用存在“ERP 已完成、Runtime 未收到”的不确定窗口，账本必须保守地要求人工恢复。
- 为什么缓存命中还要重检权限？答：Run 可能被取消、过期、禁用或 scope 变化，历史成功不能延长当前授权。
