### 10. 面试官可能追问的技术细节以及如何回答

- 问：为什么 `warehouse=None` 不能表示“所有仓库”？答：MemoryScope 是权限/业务范围的精确身份，缺失值与具体仓库是两个不同事实；把 None 当 wildcard 会直接造成跨仓库泄露。待练习。
- 问：为什么 recall 不直接加到 PersistencePort？答：持久化 mutation 和可见性读取有不同安全责任；分开端口避免后端为方便暴露通用 list/search 并绕过召回门禁。待练习。
- 问：为什么损坏一条记录时不跳过它继续返回其他记录？答：调用者无法知道返回集合是否缺失证据，partial set 会被误当完整可信结果；fail-closed 更容易由上层降级处理。待练习。
- 问：exact-scope recall 是否证明了用户有权限？答：不是；它只证明给定 scope 不会互相串数据，authenticated user/company/warehouse 权限必须在后续 Frappe/Runtime 入口重检。待练习。
